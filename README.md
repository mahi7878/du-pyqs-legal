# DU PYQS Legal Center

Static legal pages for the **DU PYQS** app, hosted with GitHub Pages.

| Page | File |
| --- | --- |
| Legal Center (home) | `index.html` |
| Privacy Policy | `privacy_policy.html` |
| Terms & Conditions | `terms_and_conditions.html` |
| Licences | `licenses.html` |

The Privacy Policy and Terms text is copied word for word from the app (`LegalContent` in
`lib/features/settings/screens/legal_text_screen.dart`). Effective date: 21 November 2026.
The icon and favicon come from the app icon (`assets/icon/app_icon.png`) and the colours from `AppColors`.
When the text in the app changes, update these pages too so both always match.

## Publish with GitHub Pages
1. Upload everything in this folder to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Your pages go live at `https://<username>.github.io/<repo>/`.
